# Prompts de imágenes IA (Canva · generate-image)

Estado al 2026-11-12. Las 4 primeras se generaron, pero en el repo solo hay **miniaturas** (de unos 200 px). Para reemplazarlas por la versión completa, sigue estos pasos:
1. Abre el enlace de cada imagen en Canva.
2. Descárgala en la resolución más alta.
3. Guárdala en `fotos/originales/<nombre>.jpg` (o `.png`).
4. Ejecuta `npm run imagenes`.
